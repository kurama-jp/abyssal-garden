## 遊び方

GitHub Pages で開くだけで動きます。WebGPU 対応ブラウザ（デスクトップの Chrome / Edge 推奨）が必要です。HTML ファイル1枚で動作するため、ダウンロードすればオフラインでも動きます。

- マウス：見回す
- W / A / S / D：泳ぐ
- E / Q：上昇 / 下降
- Shift：速く泳ぐ
- 1〜6：ビューポイントへ移動
- M：サウンド ON / OFF
